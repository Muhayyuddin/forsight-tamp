The task is to pick objects from the table and place them onto a multi-level shelf. Each object has an assigned target shelf level. The shelf has horizontal surfaces (boards) at different heights, with vertical side walls and a back wall.

The place action requires an explicit z parameter: place([obj], {'x': ..., 'y': ..., 'z': ..., 'theta': ...}).

Key constraints:
- Each object must be placed on its assigned shelf level. The z coordinate for placement is the object center height: z = surface_z + object_height/2 (where surface_z is the board's top surface z reported in the environment description). Add a small buffer: z = surface_z + object_height/2 + 0.005.
- When the observation lists "use center z >= ..." for a target assignment, use that value or a slightly higher value. Do not use the raw shelf level z / board center z, because that penetrates the shelf board.
- Objects must fit within the shelf width and depth — do not let objects overhang the shelf edges.
- Objects must fit vertically between shelf levels — the object height must be less than the clearance between the current shelf board and the board above it.
- Place larger/taller objects first to reduce collision risk for subsequent placements.
- On each shelf level, arrange objects side-by-side with small gaps to avoid collisions.
- The robot must reach into the shelf to place objects — higher levels and deeper positions are harder to reach.
- Be careful about collisions with shelf walls, back wall, ceiling board, and previously placed objects.
- Use theta=0 unless rotation is needed to fit the object on the shelf.

Planning tips:
- Start with the bottom level (easiest to reach, most clearance).
- Check that each object's height fits the clearance of its target level.
- Center objects on the shelf depth (y-axis) when possible for stability.
- Leave space between objects for the gripper to place subsequent ones.

Goal: All objects placed on their correct assigned shelf levels, fully within the shelf bounds.
