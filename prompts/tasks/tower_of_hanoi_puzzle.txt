SETUP:

- Peg B (auxiliary): empty, used as intermediate.
- Peg C (goal): must have all disks at the end, largest at bottom.

STRICT RULES (violation = failure):
1. You may only pick the TOP disk of any peg.
2. You MUST NEVER place a larger disk on top of a smaller disk.
3. Each pick-place pair moves exactly one disk.
4. A previous trace is only a failed attempt unless the Current observation shows that move in the peg states. Always plan from the Current observation, not from the trace.
5. The Full Plan must solve the entire puzzle from the Current observation. Do not output only the next one or two moves.

COORDINATE RULES (CRITICAL):
- The "Current observation:" section lists each peg's exact (x, y).
- For each place action, use the EXACT x and y of the TARGET peg — NEVER invent coordinates.
- Do NOT worry about z — the environment computes the correct stacking height automatically. Set z=0.019.
- Always set theta=0.0.
- Use only the EXACT disk names listed in the current observation. Disk names vary with the number of disks, so never copy a name from an example or another scenario.
