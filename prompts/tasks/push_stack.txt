The task is to push non-graspable object(s) to target pose(s), and when requested, build a stack on the pushed base.

Key constraints:
- Each non-graspable push object must be pushed to its assigned target pose.
- If the task includes a small graspable object, pick it and place it on top of the pushed base only after the base reaches the target.
- Use the target pose from the observation for the final push action: push([base], {"x": target_x, "y": target_y, "theta": target_theta}).
- The push primitive is a continuous gripper-contact force skill with lateral contact adjustment. If ACFM says the final target is safe, call one push action to the target pose; do not decompose it into many invented micro-pushes or retreat/re-approach strokes.
- If ACFM or rehearsal says the direct straight-line swept path is blocked, use the safest ACFM intermediate waypoint first, then push the same object to its final target.
- If the observation provides a MANDATORY DETOUR SEQUENCE, copy those push actions into the Full Plan in that exact order before any pick/place. Do not repeat the blocked final-target push as the first action.
- For stacking tasks, use the same x and y as the pushed base's final target for the small object placement.
- Set the placement z for the small object to the top surface of the base plus half the small object's height. If the observation provides a recommended z, use it.
- Do not attempt to pick the large base. A pick failure on the base means the wrong primitive was selected, not that the grasp coordinate needs adjustment.
- If rehearsal says the push ended away from the target, keep the base push before the stack placement and revise only if the feedback names a specific collision, reachability, or target-coordinate problem.

Goal: all push objects reach their target zones, and any requested small object is centered and stable on top of its pushed base.
