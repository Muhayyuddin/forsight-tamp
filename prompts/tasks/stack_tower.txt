The task is to stack objects into a tower in a specific order. Objects must be stacked bottom-to-top in the required stacking order within the designated target zone on the table. There is no basket — the stack is built directly on the table surface.

The place action requires an explicit z parameter: place([obj], {'x': ..., 'y': ..., 'z': ..., 'theta': ...}).

Key constraints:
- The bottom object must be placed on the table surface (z ≈ 0.01-0.02) within the target zone.
- Each subsequent object must be placed on top of the previous one. Compute z as the sum of heights of all objects below it.
- Objects must be centered on the object below them (same x, y).
- Larger/wider objects should be at the bottom for stability.
- Use the target zone center coordinates for x and y placement.
- Stack in the exact order specified (bottom to top).

Goal: All objects stacked in the correct order, centered and stable, within the target zone.
